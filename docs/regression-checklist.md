# Checklist manual de regresión

- [ ] Arrancar servidor con `scripts/run-dev.ps1`.
- [ ] Arrancar cliente Godot.
- [ ] Conectar y verificar sesión activa.
- [ ] Moverse, seleccionar objetivo con clic y atacar.
- [ ] Usar habilidad, guardia y poción.
- [ ] Derrotar enemigo y verificar loot.
- [ ] Fabricar `frost_blade` con `C`.
- [ ] Vender `monster_core` con `V`.
- [ ] Descubrir santuario con `R`.
- [ ] Cambiar a puerto mediante portal.
- [ ] Verificar cambio de música y landmarks.
- [ ] Morir, pulsar respawn y verificar restauración.
- [ ] Guardar/cargar con `F5`/`F9`.
- [ ] Abrir configuración con `F1`.
- [ ] Abrir galería de referencia con `F8`.
- [ ] Ejecutar `scripts/check-all.ps1`.
