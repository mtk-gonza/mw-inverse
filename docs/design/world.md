# Mundo

## Regiones iniciales

### Pradera de entrenamiento

- Nivel recomendado: 1–5.
- Función: tutorial, combate y primera misión.
- NPC principal: Arin.
- Enemigos: muñecos de entrenamiento.

### Puerto tranquilo

- Nivel recomendado: 1–10.
- Función: comercio y preparación.
- NPC principal: Lynn.
- Enemigos: ninguno en el prototipo.

## Principios

- Cada región pertenece a una instancia de servidor.
- El servidor controla entradas, salidas y estado.
- Los mapas finales utilizarán assets propios.
